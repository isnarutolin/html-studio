# html-studio

**AI 生成的 HTML，想增删改一些内容，不必再费力改 prompt，也不用反复调教AI生成符合你心意的版本。**

本地 `.html` 文件、别人分享给你的**网页链接**，都能在页面上直接改：改文字、换字体字号、拖动模块、删掉某一页，`Cmd/Ctrl + S` 就存成本地 `.html` 文件。保存前能看 diff，每一笔改动都有备份。

**也能批注**：划词留意见、回复、标记解决，批注内容跟着稿子走（导出独立 HTML / JSON）；想让大家在同一份稿子上实时看到彼此的批注，起一个本地协作服务就行（**批注不用装扩展**）。

[English](README.en.md) | 简体中文 · [常见问题](docs/FAQ.md) · [更新记录](CHANGELOG.md)

## 它解决什么

你让 AI 生成一份周报、一张看板、一个方案页，生成得挺好，只有一个数字写错了。

**原来的路**：找回那段 prompt → 补一句“把 38% 改成 39%” → 重跑 → 发现全文措辞都变了 → 再逐段对一遍。

**用 html-studio**：打开文件 → 点那个错字 → 改 → `Cmd/Ctrl + S` → 完事。其余部分一个字节没动。

## 能改什么

| | 怎么用 |
| --- | --- |
| **改文字** | 直接点进去改，`Cmd+Z` 撤销 |
| **字体 / 字号** | 选中文字（或不选中，改光标所在整段）→ 点 `Aa` 选字体和字号，也支持自定义 px |
| **拖动模块** | 点「移动」进入移动模式 → 拖住标题 / 图片 / 卡片 / 整段 section 换个位置；蓝线是落点；`Shift` 抓父级容器 |
| **删除某一页** | 点「页面」→ 列出识别到的每一页 → 定位或删除 |
| **网页也能改** | 收到别人分享的 html 网页（哪怕没有原文件）：第一次 `Cmd+S` 自动存成 `~/Downloads/<域名>-<页面>.html`，之后的保存都写这个文件 |
| **划词批注** | 点 💬 进入批注模式 → 划选文字 → 写意见；侧栏可回复、标记已解决、导出���立 HTML / JSON |

网页存成本地时，相对路径（`./style.css`、`/img/a.png`）会自动转成绝对地址，所以离线打开也不会丢样式和图片。

## 和别的方式比

| | 能直接改 | 能写回源文件 | 自动备份 | 要懂源码 |
| --- | --- | --- | --- | --- |
| 浏览器 DevTools | ✅ | ❌ 刷新即失效 | ❌ | — |
| 编辑器 + 浏览器预览 | ✅ | ✅ | 看你自己 | ✅ |
| 让 AI 重新生成 | ✅ | ✅ | ❌ 全文可能变 | ✅ 会改 prompt |
| **html-studio** | ✅ | ✅ | ✅ | ❌ |

三种都能改，区别在于**改完还剩什么**。DevTools 关掉就没了，是临时看；编辑器要你在标签里找代码；重新生成是拿确定性换省事。html-studio 只动你指的那一处，落盘前把 diff 摆给你看。

## 30 秒上手

先说清楚：**编辑**和**批注**是两条独立的线，别装错了。

| 你想干什么 | 需要装什么 | 入口 |
| --- | --- | --- |
| **编辑**：改文字、换字体、拖模块、删页、写回磁盘 | Chrome 扩展（要 native host 才有写盘权限） | `python3 extension/install.py` + 加载 `extension/` |
| **一站式（改 + 批注）**：同事零安装，打开链接就能改、能评论 | 只跑一个本地服务 | `python3 server.py --dir <目录> --host 0.0.0.0` |
| **批注（单机）**：划词留意见，导出带批注 HTML | **什么都不用装** | `python3 skills/html-annotate/scripts/annotate.py x.html` |
| **批注（多人实时）**：同一份稿子互相看到 | **什么都不用装** | `python3 skills/html-annotate/scripts/serve.py --dir ./reports` |

> **只想要批注的话，不要跑 `extension/install.py`、也不要加载扩展。**
> 批注是一条独立的线：纯 Python 标准库，零依赖，细节见 [批注](#批注在稿子上留意见) / [`skills/html-annotate/SKILL.md`](skills/html-annotate/SKILL.md)。

### 编辑 · 方式一：Chrome 扩展（推荐，能改任意本地 HTML）

```bash
git clone https://github.com/isnarutolin/html-studio.git
```

加载扩展（必做，两步）：

1. `chrome://extensions` → 打开「开发者模式」→「加载已解压的扩展程序」→ 选 `extension/` 目录
2. 扩展卡片 →「详情」→ 打开 **「允许访问文件网址」**
   ← 不开这个，本地页面不会有任何反应，也不会报错

装本地程序（可选，只在你想"写回磁盘"时才需要）：

```bash
cd html-studio
python3 extension/install.py     # 注册 native host 后，Cmd+S 直接写回原文件（带 diff + 备份）
```

**没装本地程序也能用**：`Cmd+S` 会降级成浏览器下载（通常是 `~/Downloads/`），编辑和批注功能完全不受影响。

打开任意本地 `.html`，右下角出现 ✎，点它开始编辑。

> **从 1.0.x 升级到 1.1.0 要重载扩展**：`chrome://extensions` → 本扩展卡片上的「重新加载」。
> 1.1.0 起扩展会注入所有 `http/https` 页面（这是「网页也能改」的前提），
> 浏览器可能会重新提示一次权限，属于预期变化。

**改别人分享的网页**：打开那个链接，然后点浏览器工具栏的扩展图标（或按 `Cmd+Shift+E`、或用右键菜单「HTML Studio：编辑本页」）进入编辑；地址本身就是 `.html` 结尾的网页会自动出现 ✎。第一次 `Cmd+S` 会问也不问，直接存到 `~/Downloads/`，并在提示里告诉你完整路径。

卡在哪一步？点浏览器工具栏的**扩展图标**（🧩 → HTML Studio）→ 自检页会实时检查「扩展已加载 / 文件访问权限 / 本地程序连通性」，哪项红了直接告诉你怎么办。命令行等价：`python3 extension/install.py --check`。

### 编辑 · 方式二：本地网页版（不装扩展）

```bash
python3 server.py --dir ~/Downloads      # 默认端口 7788
```

打开 <http://127.0.0.1:7788>，左侧是文件列表，右侧直接改，`Cmd/Ctrl + S` 保存。

想让它在 macOS 上常驻（登录自启、崩溃自动拉起、记住固定地址）：

```bash
python3 service.py install      # 安装并启动
python3 service.py status       # 看状态
python3 service.py logs         # 跟日志
python3 service.py uninstall    # 卸载
```

## 批注：在稿子上留意见

编辑是「我改」，批注是「我认为这里要改」。批注不动正文一个字节，只是给文字加一层高亮 + 侧栏意见。

> **批注不需要上面那套扩展，也不需要 native host。** 它只用内联的一份 JS 引擎 + （要多人时才要的）一个纯标准库 Python 服务，所以既能给别人的 HTML 一键加上，也能让 AI 在生成环节里直接调 —— 见 [作为 Agent Skill 用](#作为-agent-skill-用不装扩展不要-node)。

### 一个人批（默认，不用任何服务）

**装了扩展**：点右下角 💬（或 `Cmd/Ctrl + Shift + A`）进入批注模式 → 划选文字 → 点浮出的「批注」→ 写意见。

**没装扩展**：`python3 skills/html-annotate/scripts/annotate.py 稿子.html` 会产出 `稿子.annotated.html`，引擎已内联，双击就能批注。

**想让扩展的批注也能多人共享**：扩展选项页（`chrome://extensions` → 本扩展「详情」→「扩展程序选项」）里填上批注服务地址（例如 `http://127.0.0.1:8899`），之后任意页面点 💬 批注都会写进服务器。
留空就是纯本地 —— 批注只存你这个浏览器，换设备/发给同事都看不到。

两条路用的是同一个引擎。侧栏都可以回复、标记已解决；退出批注模式后高亮会隐起来，正文完全不变。

批注默认存在浏览器本地（`localStorage`），侧栏顶部三个按钮口可以把它们带走：

| 按钮 | 作用 |
| --- | --- |
| ⬇ | 导出批注 JSON（发给别人 / 存档） |
| ⬆ | 导入别人发来的 JSON（按 id 合并，不会盖掉你新加的） |
| ⤓ | 导出「带批注的独立 HTML」 —— 把批注烤进页面快照，别人双击就能看 |

> 批注和编辑模式是互斥的：批注靠「划选」，编辑靠 `contenteditable`，两者抢选区，所以进一个会自动退另一个。

### 多人共享（起一个本地服务）

想让大家在同一份稿子上实时看到彼此的批注，就起 `collab.py`（**零第三方依赖**，只用标准库）：

```bash
python3 collab.py --dir ~/Desktop/reports          # 默认端口 8899
python3 collab.py --dir ~/Desktop/reports --passcode 你的口令   # 需要口令时
```

它会：

1. 静态服务 `--dir` 目录里的 HTML，并在 `</body>` 前注入批注引擎 —— 把稿子丢进去，打开就带批注
2. 提供 `/api/state`、`/api/stream`（SSE 实时推送）、`/api/op` —— 谁改了批注，其他人不用刷新就能看到
3. **只允许作者本人「标记已解决 / 删除」自己的批注**（前端置灰 + 服务端校验，伪造请求也过不了）

终端会打印两个地址：本机 `http://localhost:8899/`，以及同事用的局域网地址。异地的同事就配个隧道：

```bash
bore local 8899 --to bore.pub      # 得到一个 http://bore.pub:<端口> 的公网地址
```

数据落在 `data/<docId>.json`（一个文档一个文件），可以直接备份或进 Git。

安全边界实话实说：

- **不带口令时，拿到链接的人都能看和批注**；要收紧就加 `--passcode`
- 身份是「浏览器 cookie + 署名先到先得」，防的是「顺手改个名字就删别人的」，**不是强身份认证**
- 批注服务跑在你的机器上 —— 机器睡了/关机了，链接就打不开

### 一站式：同事零安装，能改也能批注（网页版）

不想让大家装任何东西，就用网页版（`server.py`）。一个链接同时给两件事：

```bash
python3 server.py --dir ~/Desktop/reports --host 0.0.0.0   # 局域网可见
```

同事打开 `http://<你的IP>:7788/`：

| 按钮 | 能干什么 | 东西存哪 |
| --- | --- | --- |
| **编辑模式**（默认）| 直接点文字改、换字体字号、拖模块、删页 | 写回**你机器**上的文件，带 diff + 自动备份 |
| **批注**（也支持 `Cmd/Ctrl+Shift+A`）| 划选文字 → 写意见 → 回复 / 标记已解决 | 服务器 `<目录>/.edits/anno/<文件>.json`，多人实时同步 |

两个模式互斥：进批注会自动退出编辑，退出批注时批注 UI 对编辑完全不可见。
**批注绝不动正文**——保存时注入的引擎、高亮包裹、放宽过的 CSP 都会被自动剥掉还原（实测保存结果与纯编辑保存字节级一致）。

> 安全边界：`--host 0.0.0.0` 后同局域网的任何人拿到地址就能改**你 `--dir` 下的任何 HTML**。
> 所以别拿 `--dir ~` 开共享，专建一个目录（如上）跑。

### 作为 Agent Skill 用（不装扩展、不要 node）

只想让「给我加批注」变成一条命令（比如让 AI 生成完 HTML 后自己调），用 `skills/html-annotate/`。
**纯 Python 标准库，零依赖**，不需要装浏览器扩展、不需要 `install.py`、不需要 node：

```bash
python3 skills/html-annotate/scripts/annotate.py report.html        # → report.annotated.html
python3 skills/html-annotate/scripts/serve.py --dir ./reports       # 多人实时，默认 8899
```

- `annotate.py` 产出**自包含单文件**：引擎内联、放开 CSP、去掉 nonce，双击就能批注（离线可用，数据在 localStorage）
- `serve.py` 就是上面的 `collab.py`，注入 + 实时同步 + 作者权限
- 自检：`bash skills/html-annotate/tests/smoke.sh`（15 项，不联网不用浏览器）

详细用法与踩坑见 [`skills/html-annotate/SKILL.md`](skills/html-annotate/SKILL.md)。

## 保存前先看 diff
这是它敢让你直接动生产文件的原因。点保存会弹出逐行 diff，认了才落盘。

只改一个数字，落盘就是这一段：

```diff
19c19
- <p>留存仍然是短板，次月留存 38%，低于目标 6 个百分点。</p>
+ <p>留存仍然是短板，次月留存 39%，低于目标 6 个百分点。</p>
```

不满意就点「撤销保存」，源文件原样退回。

## 安全

一个能写你磁盘的东西，值得把边界说清楚：

- 只动 `$HOME` 内的 `.html / .htm / .xhtml`，路径含隐藏目录一律拒绝（网页存本地同理，只会写到你的主目录下）
- 拒绝写入空内容，防手滑把源文件清空
- 每次写盘前自动备份，可回滚到任意历史版本；恢复前再备份一次，所以恢复本身也能撤回
- 零网络请求、不收集数据、无远程代码，全程本地
- 网页版只监听 `127.0.0.1`，`/files/` 有路径越界校验

备份位置：

```
~/.html-studio/backups/        # 扩展版
<工作目录>/.edits/backups/      # 网页版
```

## 已知边界

保存是把页面当前 DOM 序列化写回文件，浏览器会顺手把排版重新规范化一遍：

- 文字、结构、class、属性都保留；`<svg>` 自闭合标签已做还原
- **缩进和换行会被重排**，`<!doctype html>` 会被规范成 `<!DOCTYPE html>`。改动越大越明显——所以请看 diff，不要盲存
- 页面若用 `<script>` 动态生成 DOM，那部分也会被一起写进文件。改这类页面先看 diff，不对就撤销，有备份兜底
- **网页存档的边界**：`blob:` 和 `data:` 里的图片按原样保留（`blob:` 存到本地会失效，需要先另存），跨域 iframe 里的内容拿不到
- **删页/拖模块的边界**：删页只是把这个块从 HTML 里去掉；如果那个页面靠 JS 数组控制翻页，删完后翻页逻辑可能需要你再看一眼（先别保存，刷新即可还原）
- **移动只做同级重排**：插到目标元素的前/后，不会把 `<div>` 塞进 `<p>`；跨容器移动时，拖到目标容器里的元素之间即可
- **批注的锚点是「字符偏移 + 前后文」**：稿子小改没事，大段删改后高亮可能对不上，但批注内容不会丢（会退化成定位失败、卡片仍在侧栏）
- **批注高亮只包文本节点**：跨段落划选会被拆成多个高亮片段（共用同一个批注 id），这是为了让版面完全不变 —— 别改回整段包裹，那样会把块级元素塞进 inline，正文会凭空多出空行
- **协作服务无强身份**：署名先到先得（绑定到浏览器 cookie），防的是误删别人批注，不是防有意的冒充

## 平台

macOS 完整支持。Linux 逻辑相同但未实机验证。Windows 的扩展部分为实验性（注册表 + `.cmd` 启动器），网页版三平台通用。细节见 [FAQ](docs/FAQ.md)。

## 部署成长期在线的入口（可选）

编辑器本身不需要这一层。想把「改 + 批注」做成一个**发给同事就能打开用**的常驻入口，用 [`server/`](server/README.md)：

```bash
cd server
./install.sh --plists --load     # 部署脚本 + 生成 launchd（开机自启）+ 重启
./install.sh --check             # 检查已部署目录与仓库是否一致
```

| 组件 | 端口 | 作用 |
| --- | --- | --- |
| `review-server.mjs` | 8899 | 批注注入 + 实时同步 + **`/p/<url>` 链接转换网关** |
| `server.py` | 7788 | 网页版一站式（改 + 批注） |
| `bore-tunnel.sh` | — | 公网隧道（带看门狗） |
| `share-link.sh` / `anno-url.sh` | — | 一眼看全部链接 / 把任意链接转成可批注地址 |

细节、安全边界和已知限制（端口会漂、带宽有限、合盖即断）见 [`server/README.md`](server/README.md)。

## 开发者

```bash
python3 tests/e2e_chrome.py      # 真 Chrome + 真 native messaging，端到端 39 项断言
python3 tests/test_collab.py     # 协作服务的单元测试：操作合并 / 身份绑定 / 作者权限
```

一条链路：`content.js`（注入编辑条，shadow DOM 隔离样式）→ `background.js`（转发消息，content script 不能直接调 `sendNativeMessage`）→ `native_host.py`（校验 + 读写文件）。改完扩展代码记得回 `chrome://extensions` 点「重新加载」。

提 PR 前先跑一遍 `tests/e2e_chrome.py`，它覆盖了保存、备份、回滚、路径校验这几条主路径。
