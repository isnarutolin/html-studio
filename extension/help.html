怎么用

  
    
    
  1. 本地文件：在访达里双击一个 .html（地址栏是 file:///... 开头），
        页面右下角会出现蓝色 ✎ 圆钮 → 点它进入编辑。
    2. 
    
  2. 网页（别人分享的链接）：直接打开那个链接，然后点工具栏的扩展图标
        （或按 Cmd/Ctrl+Shift+E、或右键 →「HTML Studio：编辑本页」）。
        地址本身是 .html 结尾的网页会自动出现 ✎。
        第一次 Cmd+S 会存成 ~/Downloads/<域名>-<页面>.html，
        提示里会告诉你完整路径；之后的保存都写这个文件。
    3. 
    
  3. 直接点文字改，Cmd+S 保存。选中文字后点 Aa 改字体字号，
        点「移动」拖模块位置，点「页面」删除某一页。
    4. 
  


  
为什么有些页面看不到 ✎

  
    
    
  1. 本地 .html 需要开「允许访问文件网址」（上面第二项），否则没有任何提示，只是安静地不注入。
        装完扩展或改完这个开关后，已经打开的页面要刷新一次。
    2. 
    
  2. 普通网站默认不挂 ✎（不然每个网站都多个球），这是故意的。
        想在任意网页上编辑，点工具栏图标或按 Cmd/Ctrl+Shift+E。
    3. 
    
  3. 扩展没有弹窗面板，工具栏图标的界面就是注入在页面里的那根工具条；
        想开这个自检页，用右键菜单「HTML Studio：自检 / 帮助」。
    4. 
    
  4. 编辑是就地改 DOM。如果网页自己会重渲染（比如 React 应用、会轮询刷新的页面），
        你的改动可能被页面覆盖 —— 这类页面建议先存成本地文件再改。
    5.
