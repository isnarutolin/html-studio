怎么用

  
    
    
  1. 在访达里双击一个本地 .html 文件（地址栏是 file:///... 开头），或者把它拖进浏览器窗口。
    2. 
    
  2. 页面右下角会出现蓝色 ✎ 圆钮 → 点它进入编辑。
    3. 
    
  3. 直接点文字改，Cmd+S 保存回原文件。
    4. 
  


  
为什么在别的页面看不到

  
    
    
  1. 扩展只对 file:// 的本地 html 生效。
    
        如果你是通过 http://127.0.0.1:7788（网页版）看文件，那个是 http 页面，扩展不会介入 —— 网页版本身就是浏览器内编辑器。
    2. 
    
  2. 扩展没有弹窗面板，所以点工具栏图标不会有小窗口弹出来；它的界面就是注入在页面里的那根工具条。
    3. 
    
  3. 装完扩展或改了「允许访问文件网址」之后，已经打开的本地页面需要刷新一次。
    4.
